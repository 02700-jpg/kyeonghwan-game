# 경환이가만든게임

Godot 4 기반 Android용 3D 다크 판타지 액션 RPG 프로토타입입니다.

## 현재 구현된 기능
- 전사, 성기사, 암살자, 마법사, 궁수 직업 선택
- 3D 던전 테스트 맵과 플레이어/몬스터
- 화면 터치 방향키 이동
- 근접 공격, 물약 회복
- 몬스터 추적 및 전투
- 경험치 획득과 레벨업

## 실행 방법
Godot 4.3 이상에서 이 저장소를 프로젝트로 열고 실행하세요.

## 개발 상태
이것은 초기 프로토타입이며 정식 완성 게임이 아닙니다. 인벤토리, 장비 및 아이템 드롭, 보스, 던전 진행, 저장/불러오기, 효과음과 밸런스 조정 및 Android APK 내보내기는 후속 개발이 필요합니다.
